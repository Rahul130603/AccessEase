# OpenDyslexic font source

Unmodified WOFF2 Regular, Bold, Italic and BoldItalic files downloaded from the official repository:
https://github.com/antijingoist/opendyslexic/tree/1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7/compiled

Licensed under the SIL Open Font License 1.1; see OFL.txt. The standalone SDK includes the font files and license. The React build serves local font assets. No third-party font service is required at runtime.
